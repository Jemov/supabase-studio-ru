# Проверка перевода

Полный патч соответствует исходному коммиту Supabase `79964102d369991a3b3adda27dc1f528c3a77457`.

Идентификатор переведенных исходников — SHA-256 от `commit + NUL + bytes(full patch)`:

```text
e5aa8ff1bfe4d53fdec41206885fcb16268c9ddd6c80927d0246371eac6ff07a
```

Для этой версии перевода перед публикацией выполнены:

- production-сборка Studio в режиме Next.js standalone;
- проверка TypeScript без ошибок;
- 497 успешных тестов в 27 файлах;
- браузерная проверка 239 фиксированных маршрутов и 294 фактических URL, всего 1 526 состояний интерфейса;
- проверки 28 типов рекомендаций Advisor, 56 панелей и 4 диалогов;
- проверка полного каталога из 77 интеграций/расширений, из них 64 доступны в проверенной конфигурации;
- проверки русского Monaco: 1 864 вызова локализации в 161 модуле, дополнение 31 отсутствующего сообщения официального пакета;
- разбор `SELECT 1` standalone SQL-парсером из собранного runtime.

В проверенном интерфейсе не осталось неразобранных английских текстов интерфейса или ошибок выполнения. Латинские имена продуктов, код, SQL и технические идентификаторы проверялись отдельно и сохранялись в исходном виде. Пользовательский контент и произвольные ответы сторонних серверов не заменяются переводчиком.

Для переносимого публикационного пакета отдельно проверены:

- скачивание чистого исходника с GitHub, применение полного патча и точное сравнение полученного индекса Git с опубликованным патчем;
- контрольные суммы всех публикуемых материалов из manifest;
- применение всех 30 переводов к оригинальным файлам закрепленных зависимостей и сравнение результатов с проверенными SHA-256;
- повторное применение переводов без изменений;
- отказ при измененной контрольной сумме зависимости до изменения остальных файлов;
- синтаксис всех скриптов и корректность JSON.

Публикационный Dockerfile использует те же закрепленные зависимости и этапы сборки, но является отдельной переносимой упаковкой. Полная Docker-сборка этой упаковки повторно не запускалась: локальный Docker daemon не ответил на проверку доступности. Результаты production-сборки, TypeScript, тестов и браузера выше относятся к ранее собранной и установленной версии с идентичным полным патчем. CI дополнительно проверяет применение патча к чистому исходнику. Приватные логи установки и содержимое пользовательской базы не публикуются.
